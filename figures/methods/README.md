# Ad-hoc figures from `docs/METHODS.md`

Scratch output for the single-purpose plot scripts (`plot_ensemble.py`,
`plot_critic_deltas.py`, `plot_generative_check.py`, `plot_beta_scan.py`, …) when
you run a command out of `docs/METHODS.md`.

Nothing here is committed and nothing in the study depends on it. **The figures
of record are in `figures/ladder/` and `figures/clamp/`**, built reproducibly by
`analysis/figures_*/make_all.py`; see `docs/RESULTS.md`.
